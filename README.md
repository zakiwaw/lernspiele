# Lernspiele

Zwei kleine Lernspiele für Kinder, gemacht für das iPad (Touch, große Tasten, läuft im Browser).

- **Formen** (ab 3 Jahren): Drei Spielarten: *Finden* (gleiche Form suchen), *Zeig mir* (die Stimme nennt eine Form, ohne Vorlage) und *Nachfahren* (Umriss mit dem Finger zeichnen). Eine Form kann gezielt geübt werden, falsche Formen werden beim Antippen benannt, nach 10 Aufgaben gibt es eine Pause mit einer Idee zum Suchen im Zimmer.
- **Muster** (ab 5 Jahren): Was kommt als Nächstes? Themen Farben, Tiere, Blumen, Fahrzeuge und Flugzeuge, drei Stufen.

## Auf dem iPad spielen

1. Die Seite in Safari öffnen (GitHub-Pages-Link).
2. Teilen-Symbol, dann „Zum Home-Bildschirm". Danach startet es wie eine App im Vollbild.

Die Spiele sind reine HTML-Dateien ohne Server und ohne Internetzugriff zur Laufzeit (die Bilder-Schrift liegt im Ordner `fonts`).

Lizenzhinweis: Die Symbole stammen aus der Tabler-Icons-Schrift (MIT-Lizenz).

## Für Eltern

- Die Einstellungen (Spielart, Form, Schwierigkeit, Thema) liegen hinter dem Zahnrad oben links. Zum Öffnen das Zahnrad etwa eine Sekunde gedrückt halten, damit Kinder es nicht aus Versehen öffnen.
- Die Spielseiten sind gesperrt: Sie scrollen und wackeln nicht, auch wenn das Kind beim Tippen wischt.
- Tipp für den iPad-Bildschirm: Einstellungen, Bedienungshilfen, Geführter Zugriff einschalten, dann in der App dreimal die Seitentaste drücken. So bleibt das Kind im Spiel.
