# Lernspiele

Zwei kleine Lernspiele für Kinder, gemacht für das iPad (Touch, große Tasten, läuft im Browser).

- **Formen** (ab 3 Jahren): Kreis, Stern, Herz, Viereck und Dreieck erkennen. Mit Vorlesen und Hilfe, wenn die falsche Form getippt wird.
- **Muster** (ab 5 Jahren): Was kommt als Nächstes? Themen Farben, Tiere, Blumen, Fahrzeuge und Flugzeuge, drei Stufen.

## Auf dem iPad spielen

1. Die Seite in Safari öffnen (GitHub-Pages-Link).
2. Teilen-Symbol, dann „Zum Home-Bildschirm". Danach startet es wie eine App im Vollbild.

Die Spiele sind reine HTML-Dateien ohne Server und ohne Internetzugriff zur Laufzeit (die Bilder-Schrift liegt im Ordner `fonts`).

Lizenzhinweis: Die Symbole stammen aus der Tabler-Icons-Schrift (MIT-Lizenz).
